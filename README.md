# repodoctor

[![CI](https://github.com/jagadish-kumar-j/repodoctor/actions/workflows/ci.yml/badge.svg)](https://github.com/jagadish-kumar-j/repodoctor/actions/workflows/ci.yml)

A CLI that checks what's missing on your machine to run any repo.

## Install for development

```powershell
python -m venv .venv
.venv\Scripts\pip install -e ".[dev]"
.venv\Scripts\pytest
```
